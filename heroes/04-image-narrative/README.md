# Image-First Visual Narrative Hero (Svalbard Ice Chronology)

An atmospheric, image-driven hero section structured around polar glaciological expeditions. Rather than centering headline text over a stock photo, it anchors data and narrative along intentional edge perimeters, giving full prominence to an evocative, pure CSS and SVG arctic landscape.

## Design Movement & Rationale
- **Movement**: Environmental Narrative & Field Expedition Observational Canvas.
- **Visual Composition**: Deep night indigo sky, flowing aurora borealis gradients, layered mountain ridge silhouettes, and topographic contour vectors.
- **Edge-Anchored Layout**: Top-left coordinates, top-right telemetry cluster, mid-right core depth selector, and bottom-left narrative block create a balanced framing that lets the center breathe.
- **Zero Remote Image Dependencies**: All mountains, contours, aurora layers, and crosshairs are built entirely with CSS and inline SVGs.

## Interactive Features
- **Ionospheric Aurora Toggle**: Turn the simulated atmospheric aurora emission on or off with smooth opacity transitions.
- **Stratigraphic Core Depth Selector**: Switch between Surface Firn (2026), Sub-Glacial Ice (1840), and Basal Bedrock (12,000 BCE) with responsive narrative updates.
- **Surveyor Crosshair Reticle**: Tracks mouse cursor coordinates across the landscape with live latitude/longitude calculation.
