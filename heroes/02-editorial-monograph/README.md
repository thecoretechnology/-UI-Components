# Editorial Monograph Hero (Cahier Critique)

A literary, broadsheet-inspired hero section structured around architectural critique, classical book typography, and pure CSS directional sunlight simulation over a carved travertine colonnade.

## Design Movement & Rationale
- **Movement**: French architectural editorial monograph (*Cahiers Critiques*, Domus, Casabella).
- **Typography**: High-contrast modern serif display (`Playfair Display`, Georgia) paired with refined geometric sans and monospaced catalog references.
- **Rhythm & Structure**: Top running folio header with ISSN/issue metadata, deep negative space, two-column asymmetric reading grid, dropped initial cap, pull quote marginalia, and bottom colophon rule.
- **Zero-Dependency Architectural Visual**: A pure CSS dimensional colonnade with fluted relief columns, cast shadow calculations, and a three-tier solar angle switcher (*Morning*, *Zenith*, *Golden Hour*).

## Interactive Capabilities
- **Solar Light Controller**: Toggle between Morning 09:30, Noon Zenith 12:00, and Golden Dusk 18:00 light simulations to watch column shadows and warm ambient hues cast across the page.
- **Audio Dispatcher**: Simulated lecture recording player with interactive play/pause toggle.
- **Library Bookmark**: Interactive "Save to My Library" action with visual feedback and polite toast notification.

## Scoped Tokens
- Background: `#faf8f5` (warm archival rag paper)
- Ink: `#1c1917` (deep carbon black)
- Travertine: `#e8e2d5` (warm stone tone)
- Scope Prefix: `.hr-mono-*`
