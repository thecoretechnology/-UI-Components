# Quiet Luxury Hero (Maison Hémisphère)

A serene, restrained hero section that expresses true luxury through deliberate negative space, whispering Bodoni typography, and tactile horological craft rather than ostentatious gold gradients.

## Design Movement & Rationale
- **Movement**: Haute Horlogerie & Parisian Salon Restraint (Place Vendôme, Le Brassus).
- **Vast Negative Space**: Generous breathing room on warm alabaster/ivory ground (`#faf9f6`) with whisper-thin 1px linen border rules.
- **Understated Craft**: Centers on hand-turned rose-engine Guilloché dials rather than flashy tech mockups or mass-market claims.
- **Zero Remote Image Dependencies**: The engine-turned dial rosette and lighting sheens are rendered using pure SVG mathematics and CSS radial gradients.

## Interactive Features
- **Incident Ambiance Switcher**: Toggle between Diffuse Daylight, Warm Salon Candlelight, and Razor Atelier Beam to observe dynamic light reflection shifts across the silver dial.
- **Interactive Light Sheen**: Hovering the medallion shifts the specular reflection point across the rosette geometry.
- **Discreet Salon Drawer**: Expandable inline private viewing appointment request with confidential concierge selection.

## Scoped Tokens
- Background: `#faf9f6` (warm alabaster)
- Ink: `#262522` (warm graphite)
- Border: `#e8e5dc` (fine linen tone)
- Scope Prefix: `.hr-lux-*`
