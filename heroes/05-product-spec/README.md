# Product-Led with Technical Annotations Hero (Vanguard Chronometre)

A precision-engineered, product-first hero section that treats an analog mechanical instrument as an authentic object of study. Built around architectural caliper annotations, detailed metallurgy specifications, and a fully functional pure CSS monopusher chronograph stopwatch.

## Design Movement & Rationale
- **Movement**: Precision Engineering Horology & Technical Specification Drafting.
- **Composition**: Split layout pairing a rigorous dimension/escapement table on the left with a detailed mechanical watch apparatus and pointer callouts on the right.
- **Micro-Machined Details**: Grade 5 titanium, carbon DLC, and patinated bronze casing finishes rendered with pure CSS gradients, dial tracks, hour indices, and 30-minute registers.
- **Zero Remote Image Dependencies**: The watch case, bezel, hands, indices, and caliper lines are drawn entirely in CSS.

## Interactive Features
- **Real-Time Functional Chronograph**: Click the physical monopusher button at 2 o'clock or the stopwatch controls to start, stop, and reset the central orange sweep second hand and 30-minute register with live millisecond timing.
- **Metallurgy Switcher**: Dynamically toggle between Grade 5 Titanium, Carbon DLC Matte, and Patinated Bronze casing finishes.
- **Blueprint Action**: Dispatches an interactive blueprint spec download notice.
