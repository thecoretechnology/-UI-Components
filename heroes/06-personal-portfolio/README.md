# Personal Portfolio Hero (Elin Lindqvist — Type Designer)

A characterful, non-generic personal portfolio hero section designed for a Stockholm-based type designer and epigrapher. Replaces freelancer cliches with an interactive typographic specimen foundry testing rig.

## Design Movement & Rationale
- **Movement**: Contemporary Scandinavian Type Foundry & Epigraphic Atelier.
- **Visual Composition**: Warm paper ground, fine dark borders, structured ledger rows, and an asymmetric split between architectural monograph commissions and interactive letterform testing.
- **Characterful Identity**: Authentic Swedish cultural context (Stockholm, Södermalm, Royal Dramatic Theatre commissions) rather than generic tech buzzwords.
- **Zero Remote Image Dependencies**: All layouts, specimen borders, and letterform stages use native typography and CSS styling.

## Interactive Features
- **Dynamic Variable Weight Slider**: Adjust the continuous weight axis (`wght` 100 Hairline to 900 Black) in real time to morph the oversized headline glyph and body phrase simultaneously.
- **Editable Glyph Matrix**: Click directly into the giant letterform to test any custom character, glyph, or Unicode diacritic.
- **Specimen Ledger**: Switch between *Nordisk Grotesk*, *Epigraph Antiqua*, and *Sigtuna Monumental* with instant live preview updates.
- **Optical Size Presets**: Toggle between Caption, Text, and Display tracking presets.

## Scoped Tokens
- Background: `#f8f6f0` (archival book paper)
- Ink: `#18181b` (dense charcoal)
- Border: `#e4e0d5` (fine linen tone)
- Scope Prefix: `.hr-folio-*`
