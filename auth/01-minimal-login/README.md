# 01 Minimal Login

A typography-led, compact authentication interface prioritizing clean whitespace, understated borders, and crisp legibility without unnecessary card borders or floating shadow slop.

## Design Highlights
- **Typographic hierarchy**: Compact 32px headline paired with high-contrast neutral palette.
- **Accessible password visibility**: Interactive SVG toggle with `aria-pressed` and dynamic `aria-label`.
- **Honest recovery disclosure**: "Lost passphrase?" reveals an inline simulation card instead of pretending network dispatch occurred.
- **Zero remote assets**: Pure HTML, CSS custom properties, and inline SVGs.

## Class Prefix
All classes are strictly scoped under `.auth-min-*`.
