# 04 Editorial / Luxury Authentication

A salon-inspired authentication interface built for exclusive archives and cultural publications. Features *Playfair Display* serif headlines, refined folio headers, diamond-separated rules, warm bronze hairline accents, and an archival colophon footer.

## Highlights
- **Literary aesthetics**: Cream/ivory background (`#f7f5f0`) with serif typography and small-caps tracking.
- **Accessible passkey toggle**: Clean SVG visibility button with full ARIA state tracking.
- **Archival patronage links**: Interactive demo prompts for forgotten passkeys and patronage admission requests.

## Class Prefix
All classes are scoped under `.auth-lux-*`.
