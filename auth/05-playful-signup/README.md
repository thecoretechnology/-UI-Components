# 05 Playful Sign-up

A creative studio registration flow featuring expressive typography, hand-coded CSS vector mascot badges, craft pill selectors, handle availability indicators, and an interactive 3-tier password strength gauge.

## Highlights
- **Playful creative theme**: Warm peach/amber background (`#fffbeb`) with offset hard shadow borders.
- **Dynamic handle verification**: Real-time availability indicator when typing alphanumeric handles.
- **Interactive password strength meter**: 3 colored segments (Weak, Good, Stellar) reacting to length and entropy.
- **Zero remote dependencies**: Pure CSS animations and vector SVGs.

## Class Prefix
All classes are scoped under `.auth-play-*`.
