# 08 Workspace / Team Invitation

A contextual team invitation screen showcasing pre-filled, locked inviter details, an explicit team role badge, and structured account creation controls with honest demo simulation.

## Design Highlights
- **Contextual inviter card**: Displays inviter initials, inviting team name ("Core Infrastructure"), and pending expiration notice.
- **Locked invited email**: Read-only input field with dedicated badge preventing token mismatch issues.
- **Two-column password grid**: Features dual password visibility toggles and matching validation.
- **Dual action hierarchy**: Clear distinction between accepting the invitation and declining it (with non-destructive demo disclosure).

## Class Prefix
All classes are strictly scoped under `.auth-team-*`.
