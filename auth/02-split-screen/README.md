# 02 Split-screen Authentication

An asymmetrical 42% / 58% split composition pairing an editorial architectural manifesto and isometric vector prism on the left with an interactive dual-mode authentication console on the right.

## Features
- **Asymmetrical composition**: Editorial quote, telemetry coordinates, and vector geometry in pure CSS and SVG.
- **Dual-mode toggle**: Easily toggles between "Sign In" and "Request Access", updating relevant inputs and submit text.
- **Accessible password visibility**: Interactive SVG toggle with `aria-pressed` states.
- **Responsive adaptation**: Automatically stacks on mobile and tablet preview modes.

## Class Prefix
All classes are scoped under `.auth-split-*`.
