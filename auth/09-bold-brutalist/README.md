# 09 Brutalist Authentication

A neo-brutalist operator clearance terminal featuring thick 3px black borders, 7px hard drop shadows, high-contrast monospace typography, and a distinctive rectangular submit action.

## Design Highlights
- **Stark visual architecture**: 0px border-radius, hard black shadows (`7px 7px 0 #000`), and industrial yellow/black accents.
- **Text-based password toggle**: Accessible `[SHOW]` / `[HIDE]` monospace button replacing generic circular icons.
- **Physical clearance level selector**: Industrial radio pill matrix with instant dark/yellow inversion state.
- **High-contrast feedback banner**: Dedicated terminal alerts with hard borders and explicit validation states.

## Class Prefix
All classes are strictly scoped under `.auth-brutal-*`.
