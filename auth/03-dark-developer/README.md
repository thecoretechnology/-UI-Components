# 03 Dark Developer Login

A terminal-inspired developer console for distributed engineering teams. High contrast `#0d1117` surface, monospaced typography, cluster selector radio pills, dual authentication mechanisms (SSH/Password and Personal Access Token), and live CLI curl snippet generation.

## Features
- **Dual authentication protocols**: Password vs PAT (`pat_live_...`) with contextual validation.
- **Cluster environment selection**: Dynamic target cluster pills (`us-east-1`, `eu-west-1`, `sandbox`).
- **Interactive CLI snippet**: Live updates as operator handle or cluster changes, with 1-click clipboard copy.
- **Password & token visibility**: Secure eye toggles with complete ARIA attributes.

## Class Prefix
All classes are scoped under `.auth-dev-*`.
