# 05 Single-Plan Pricing

A focused, single-offer presentation demonstrating how to showcase a high-conviction perpetual license without the conventional 3-tier card layout.

## Design Highlights
- **Single-offer clarity**: Highlights a one-time perpetual license ($189) with direct inclusions, avoiding artificial tiered choices.
- **Interactive add-ons**: Modular checkboxes allow purchasers to dynamically add Priority Support (+$49) or Multi-Seat Deployment (+$99) with live math calculation.
- **Detailed deliverables ledger**: Clear breakdown of what is included (unminified source, commercial rights, offline air-gapped activation).
- **Asymmetric two-column split**: Left side focuses on monetary value and action; right side clarifies scope and assurances.

## Class Prefix
All styles are strictly scoped under `.pr-single-*`.
