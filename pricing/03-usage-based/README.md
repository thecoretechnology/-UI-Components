# 03 Usage-Based Pricing

A clean, light engineering telemetry and cloud console workbench demonstrating pay-as-you-go ingestion with a complimentary monthly allowance, interactive traffic scrubber, and real-time cloud invoice ledger.

## Design Highlights
- **Crisp cloud console aesthetic**: Off-white and light slate backgrounds (`#f8fafc`, `#ffffff`) with technical electric blue (`#2563eb`) and emerald free-tier indicators.
- **2-Column split workbench**: Left side hosts the interactive ingestion scrubber and volume archetype presets; right side models a live cloud invoice statement.
- **Transparent mathematics**: Explains unit calculations ($0.0020/1k calls) with first 100K calls waived perpetually.
- **Developer utilities**: Interactive sandbox token provisioner and terminal `curl` snippet showing header authentication.

## Class Prefix
All styles are strictly scoped under `.pr-usage-*`.
