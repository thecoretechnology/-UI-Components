# 02 Minimal Editorial Pricing

A typography-led, broadsheet-inspired pricing colophon featuring classical Didot serif styling, fine hairline dividers, an direct patronage narrative, and an interactive multi-currency ledger.

## Design Highlights
- **Broadsheet composition**: Paired manifesto column with structured tabular ledger lines.
- **Interactive currency switcher**: Dynamic exchange conversions between USD ($), EUR (€), and GBP (£).
- **Typographic restraint**: Generous whitespace, *Playfair Display* serif accents, and monospace folios.
- **Client-side simulation**: Transparent demo disclosures upon edition selection.

## Class Prefix
All styles are strictly scoped under `.pr-edit-*`.
