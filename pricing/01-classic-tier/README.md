# 01 Classic Tier Comparison

A restrained, aligned tier comparison grid featuring three cleanly structured columns (Community, Professional, Team Business) with hairline border divisions and tabular feature alignments rather than floating cards.

## Design Highlights
- **Tabular grid structure**: Aligned header, pricing, call-to-action, and capability rows across all tiers.
- **Restrained hierarchy**: Subtle inset border on the featured tier without artificial neon glows or gradients.
- **Honest simulation disclosure**: Interactive plan buttons trigger clear client-side selection feedback.
- **Zero remote dependencies**: Pure HTML, CSS custom properties, and inline SVGs.

## Class Prefix
All styles are strictly scoped under `.pr-classic-*`.
