# 06 Dark Technical FAQ

A developer-focused dark engineering console featuring deep slate surfaces (`#0a0e17`), monospace HTTP method verbs, syntax-formatted configuration blocks, and clipboard copy buttons.

## Design Highlights
- **Executive Technical Aesthetics**: Replaces flashy neon gradients with calibrated obsidian surfaces, 1px slate borders, and muted cyan accents (`#38bdf8`).
- **Interactive Code Snippets**: Pre-formatted cURL probes and nginx asset blocks equipped with one-click copy feedback.
- **Infrastructure Telemetry**: Production status indicators, runtime verification badges, and air-gapped deployment guarantees.

## Class Prefix
All styles are strictly scoped under `.faq-tech-*`.
