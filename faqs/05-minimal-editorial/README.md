# 05 Minimal Editorial FAQ

A print-inspired broadsheet FAQ composition featuring warm parchment surfaces, Playfair Display serif typography, publication folios, numbered question rows, and zero unnecessary card boxes.

## Design Highlights
- **Cardless Broadsheet Hierarchy**: Pure editorial typesetting structured with double hairline rules, publication running folios, and bibliographic citations.
- **Serif Typographic Cadence**: Scaled serif question triggers with sectional glyph indicators (`§`) and calibrated line lengths.
- **Colophon Footer**: Publication metadata grid documenting typography, layout style, and non-commercial demo disclosures.

## Class Prefix
All styles are strictly scoped under `.faq-edit-*`.
