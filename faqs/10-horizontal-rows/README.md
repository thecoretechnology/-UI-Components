# 10 Horizontal / Full-Width FAQ

A wide-format briefing ledger aligning questions across 3 deliberate desktop columns (Domain Pill + Index, Question Statement, Reading Time + Action), revealing an expansive dual-aspect answer ledger rather than a standard accordion.

## Design Highlights
- **Deliberate 3-Column Alignment**: Structures queries with dedicated categorical taxonomy, clear question spans, and metadata readouts.
- **Dual-Aspect Briefing Ledger**: The expanded panel splits between a left-hand direct architectural narrative (~62%) and a right-hand empirical benchmark reference card (~38%).
- **Responsive Stack Physics**: Gracefully reconfigures to a vertical mobile list without clipping wide-table layouts.

## Class Prefix
All styles are strictly scoped under `.faq-row-*`.
