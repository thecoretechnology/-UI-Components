# 08 Help Center FAQ

A comprehensive Help Desk / Support Portal layout pairing a search hero with quick topic navigation tiles, popular question accordions, and an interactive simulated support intake ticket modal.

## Design Highlights
- **Help Center Portal Architecture**: Dedicated search bar, 4 domain quick-tiles (Getting Started, Billing, API, All), and topic badge indicators.
- **Support Escalation Desk**: Real-time engineer availability indicator with an accessible priority ticket modal dialog.
- **Synchronized Search & Topic Filtering**: Search queries and topic selections work in tandem with dynamic result counts and an empty state.

## Class Prefix
All styles are strictly scoped under `.faq-help-*`.
