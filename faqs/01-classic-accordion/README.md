# 01 Classic Accordion FAQ

A clean, cardless FAQ accordion layout featuring centered high-legibility typography, subtle hairline dividers, keyboard navigation, and an interactive runtime mode switch between single-open (exclusive) and multi-open (simultaneous) behavior.

## Design Highlights
- **Cardless Clean Typography**: Replaces elevated card boxes with an editorial list style separated by subtle 1px dividers.
- **Dual Behavior Modes**: Real-time switch supporting both traditional single-accordion expansion and multi-panel simultaneous expansion.
- **WAI-ARIA & Keyboard Compliant**: Dynamic `aria-expanded` and `aria-controls`, labeled regions, chevron indicator rotation, and full arrow key (`Up`/`Down`/`Home`/`End`) traversal.

## Class Prefix
All styles are strictly scoped under `.faq-classic-*`.
