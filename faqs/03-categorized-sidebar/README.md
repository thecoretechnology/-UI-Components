# 03 Categorized FAQ with Sidebar

A categorized knowledge directory featuring a dedicated vertical category rail on desktop that transforms into a horizontal scroll strip on mobile devices.

## Design Highlights
- **Topic Navigation Rail**: Granular categories (Account, Billing, Features, Security) with dynamic count badges and active states.
- **Dynamic Filter Summary**: Header bar displaying real-time visible question tallies and active topic tags.
- **Adaptive Layout**: Side-by-side split desktop navigation converting seamlessly to touch-friendly horizontal swipe controls on smaller viewports.

## Class Prefix
All styles are strictly scoped under `.faq-cat-*`.
