# 02 Split-Screen FAQ

An asymmetric 35/65 split-screen FAQ composition pairing a sticky left-hand information and direct inquiry panel with expandable question cards on the right.

## Design Highlights
- **Asymmetric Composition**: Separates high-level technical support status and direct question intake from granular accordion responses.
- **Support Desk Telemetry**: Real-time operational indicator, response pledge, and working ticket simulation form.
- **Monospace Numbered Queries**: Clean numbered badges (`01`–`05`) and generous indented panel bodies.

## Class Prefix
All styles are strictly scoped under `.faq-split-*`.
