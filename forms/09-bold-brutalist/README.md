# Bold Brutalist Contact Form

A neo-brutalist dispatch terminal with assertive typography, high-contrast borders, physical drop shadows, and indexed field cells.

## Features
- **Tactile Brutalist Aesthetic**: 3px solid borders, hard `7px 7px 0` drop shadows, and zero border radius.
- **Graphic Indexing**: Numbered input blocks (`[01] SENDER`, `[02] VECTOR`, etc.) creating high visual clarity.
- **Dispatch Speed Switcher**: Heavy pill options with tactile hover and active depressed physics.
- **Accessible & High-Contrast**: Strict 15:1+ text contrast, visible focus outlines, and screen-reader polite error containers.
- **Honest Demo Status**: Localized simulation disclaimer acknowledging zero outbound transmission.

## Tokens
- Prefix: `.cf-brutal-*`
- Background: `#fffbe6`
- Card: `#ffffff`
- Borders & Text: `#000000`
- Accent: `#facc15`
- Error: `#dc2626`
