# Editorial / Personal Contact Form

A typography-led literary contact page for writers, essayists, researchers, and fellows that pairs an authoritative colophon with an unpretentious, compact message form.

## Features
- **Editorial Colophon**: Detailed narrative context, direct archive coordinates, and public PGP fingerprint.
- **Asymmetric Composition**: Balanced two-column grid transforming gracefully into a stacked reading experience on mobile.
- **Nature of Inquiry Selector**: Explicit routing for monograph critiques, speaking invitations, and fellowships.
- **Warm Literary Palette**: Paper/linen background with deep ink typography and subtle rules.
- **Honest Demo State**: Local validation with non-telemetry confirmation banner.
