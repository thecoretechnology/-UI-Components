# Booking / Consultation Request Form

An appointment intake form for advisory sessions, design critiques, and technical deep-dives with selectable meeting types, preferred date pickers, time windows, and timezone selection.

## Features
- **Format Cards**: Radio-backed session cards (30-min discovery, 60-min deep dive, 45-min critique).
- **Date & Time Selectors**: Native date input with minimum date boundaries and window options.
- **Honest UI**: Clear declaration that the form records an intake request subject to mutual availability.
- **Accessibility**: ARIA radiogroups, keyboard focus rings, and explicit `<label>` connections.

## Tokens
- Prefix: `.cf-book-*`
- Background: `#f8fafc`
- Surface: `#ffffff`
- Accent: `#0f172a`
- Card Active: `#eff6ff`
