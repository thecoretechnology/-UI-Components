# Dark Premium Contact Form

A private advisory consultation form styled with restrained low-contrast dark surfaces, serif display typography (`Playfair Display`), hairline borders, and contact channel preferences without neon glows or gradients.

## Features
- **Design Aesthetic**: Executive advisory theme with deep charcoal background (`#090a0f`), subtle borders (`#232533`), and monochrome typography.
- **Form Controls**: Client principal details, practice area selection, context textarea, and channel preference checkboxes.
- **Validation**: Strict validation with accessible focus routing and demo status reporting.

## Tokens
- Prefix: `.cf-dark-*`
- Background: `#090a0f`
- Surface: `#12131a`
- Text: `#f4f4f5`
- Border: `#232533`
