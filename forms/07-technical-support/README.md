# Developer / Technical Support Form

A structured diagnostic intake console designed for engineering groups, API platforms, and cloud infrastructure reporting.

## Features
- **Categorized Issue Domains**: API gateway, auth/OAuth, latency, SDK anomalies, and security disclosures.
- **Severity Matrix**: P1 through P4 impact buttons with priority color-coding.
- **Environment Parameters**: Dedicated inputs for target OS, language runtime, and SDK versioning.
- **Monospace Repro Field**: Preformatted syntax log buffer for stack traces and reproduction code snippets.
- **Accessibility**: Explicit label linkages, keyboard-focusable severity pills, and inline error announcements.

## Tokens
- Prefix: `.cf-tech-*`
- Background: `#0f1117`
- Surface: `#161822`
- Accent: `#6366f1` (Indigo console accent)
- Error: `#f43f5e`
