# Split Contact Layout

An asymmetrical split layout that displays context, location, direct studio desk contacts, and typical response hours on one side, paired with an inquiry form and subject category pills on the other.

## Features
- **Asymmetric Composition**: 38% informative context pane, 62% actionable inquiry form.
- **Subject Filtering**: Quick radio pills to categorize incoming inquiries.
- **Accessibility**: Full keyboard tab navigation, visible `:focus-visible` pill outlines, and semantic ARIA labeling.
- **Fluid Layout**: Collapses smoothly into a single unified column on narrower viewports.

## Tokens
- Prefix: `.cf-split-*`
- Aside Background: `#0f172a`
- Surface: `#ffffff`
- Accent: `#2563eb`
