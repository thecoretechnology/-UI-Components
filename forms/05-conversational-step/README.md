# Friendly Conversational Step Form

A multi-step, welcoming inquiry wizard that divides questions into 3 conversational steps with a live progress bar, per-step validation, and back/next navigation controls.

## Features
- **Progress Tracking**: Step indicator ("Step 1 of 3") and percentage fill progress bar.
- **Per-Step Validation**: Validates required inputs before allowing the user to advance to the next step.
- **State Preservation**: Moving back and forth maintains all previously filled inputs and selections.
- **Keyboard Navigation**: Pressing `Enter` in single-line inputs automatically triggers the "Continue" step validation.

## Tokens
- Prefix: `.cf-conv-*`
- Background: `#f8fafc`
