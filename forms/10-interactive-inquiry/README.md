# Interactive Inquiry Form

An adaptive inquiry routing console that morphs based on selected department (Enterprise Sales, Partnerships, Press & Media, Careers) with dynamic validation rules.

## Features
- **Dynamic Routing Tabs**: Accessible radiogroup cards for department switching with keyboard and mouse support.
- **Adaptive Form Panes**: Contextual fields update smoothly (seats & organization for Sales, publication & deadline for Press, portfolio link for Careers).
- **Dynamic Field Validation**: Required fields dynamically match the active department.
- **Accessible Interactions**: ARIA radiogroup, keyboard tab traversal, role status live regions for feedback.
- **Honest Demo State**: Clear banner acknowledging simulated in-browser submission.
