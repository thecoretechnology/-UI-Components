# Minimal Studio Contact Form

A restrained contact form with generous whitespace, carefully aligned field pairs, thin borders, and a direct submit action without unnecessary cards or floating shadows.

## Features
- **Design Philosophy**: Minimalist studio aesthetic with subtle typography and clean field alignment.
- **Validation**: Required-field validation for name, email format, and message content.
- **Accessibility**: Explicit `<label>` associations, `aria-live` error descriptions, and clear focus outlines.
- **Demo Mode**: Dispatches an honest inline confirmation notice on submit without sending network requests.

## Tokens
- Prefix: `.cf-studio-*`
- Background: `#fcfbf9`
- Text: `#18181b`
- Border: `#e4e4e7`
