# Minimal Uniform Grid Gallery

A Swiss-inspired, high-precision exhibition grid with uniform 1:1 square proportions, catalog indices, and interactive grid density controls (2, 3, or 4 columns).

## Architecture
- **Class Prefix:** `.gal-uniform-*`
- **Uniform Proportions:** Strict 1:1 aspect ratio containers with subtle image scaling micro-interactions.
- **Interactive Density Switcher:** User can dynamically switch between 4-column, 3-column, and 2-column layouts without reloads.
- **Clean Accessibility:** Semantic `<figure>` and `<figcaption>` elements, descriptive alt text, accessible ARIA density toggle controls.
- **Zero Dependencies:** Pure HTML, CSS, and vanilla JavaScript.
