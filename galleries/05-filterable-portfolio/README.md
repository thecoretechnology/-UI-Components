# Filterable Portfolio Gallery

A clean multidisciplinary studio portfolio featuring live category filtering (All, Architecture, Portraits, Nature), active count badges, accessible tabs, and dedicated empty-state fallback handling.

## Architecture
- **Class Prefix:** `.gal-filter-*`
- **Dynamic DOM Filtering:** Instant category switching using vanilla JavaScript without full page refreshes or external dependencies.
- **Accessible Navigation:** Semantic `role="tablist"` and `role="tab"` attributes with synchronized `aria-selected` states.
- **Empty State & Reset:** Dedicated empty state banner with a one-click reset button returning the user to the complete catalogue.
- **Responsive 3-Column Grid:** Gracefully collapses to 2 columns on tablets and a single column on mobile devices.
