# Full-Bleed Immersive Gallery

A widescreen 21:9 cinematic exhibition panorama featuring edge-to-edge imagery, subtle geographic coordinate overlays, smooth cross-fades, and a chapter timeline bar.

## Architecture
- **Class Prefix:** `.gal-immersive-*`
- **Cinematic Ratio:** Scaled 21:9 on desktop, adapting to 16:9 on tablets and 4:3 on mobile devices with zero letterboxing distortion.
- **Cross-Fade Layering:** Hardware-accelerated CSS opacity cross-fades smoothly between panoramic landscapes without sudden layout shifts.
- **Interactive Chapter Timeline:** Accessible chapter tabs provide direct access to all 5 documented frontier locations.
- **Controlled Playback:** Manual user control with optional auto-cycle mode that automatically cancels upon user intervention.
