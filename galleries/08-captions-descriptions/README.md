# Image Gallery with Captions

An oceanic archival exhibition documenting pelagic deep-sea records with four typographically distinct caption treatments: side-by-side drop-caps, full-width metadata ledgers, expandable curator notes, and simulated acoustic audio guides.

## Architecture
- **Class Prefix:** `.gal-caption-*`
- **Typographic Diversity:** Integrates drop-caps (`.gal-caption-dropcap`), monospace technical coordinate stamps, and taxonomic field ledgers.
- **Expandable Curator Drawer:** WAI-ARIA accessible toggle with smooth chevron flip and hidden content disclosure.
- **Interactive Audio Simulator:** Interactive play button with animated CSS audio frequency waveform and transcript disclosure.
- **Zero Dependencies:** Pure semantic HTML5 and vanilla JavaScript.
