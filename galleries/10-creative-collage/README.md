# Creative Collage Gallery

A multi-planar, avant-garde design collage featuring intentional overlaps, subtle angle rotations, layered elevations, and an interactive layout shuffle control.

## Architecture
- **Class Prefix:** `.gal-collage-*`
- **Multi-Layer 12-Column Grid:** Built using a 12-column grid with deliberate cell overlaps and staggered z-indexes.
- **Dynamic Elevation & Hover:** Hovering or focusing any collage plate brings it to the top layer with smooth expansion.
- **Interactive Layout Shuffle:** Toggle button transitions CSS grid coordinates and rotation angles into an alternative arrangement.
- **Responsive Clean Reflow:** Smoothly settles into a structured 2-column or 1-column layout on tablet and mobile viewports with zero horizontal overflow.
