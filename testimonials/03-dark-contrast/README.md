# 03 Dark, High-Contrast Testimonial

A premium, bold typography testimonial section on a stark obsidian backdrop (`#050505` / `#0d0d0d`) featuring razor-sharp geometric borders, structured deployment telemetry specs, and an audit verification token.

## Design Highlights
- **Stark High-Contrast Palette**: True obsidian surface with stark white typography (`#ffffff`), no neon glows, and no blurred glassmorphism.
- **Enterprise Verification Metadata**: Includes audit pill, corporate identity, and a simulated cryptographic ingestion token.
- **Structured Deployment Specs**: Direct, scannable table of production workload metrics (Ingress rate, topology, SLA).
- **Interactive Copy Action**: Functional click-to-copy trigger on the verification hash.

## Class Prefix
All styles are strictly scoped under `.ts-dark-*`.
