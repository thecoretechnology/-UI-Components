# 02 Customer Story with Portrait

An asymmetric case study layout pairing an architectural portrait avatar and author metadata sidebar with a comprehensive engineering testimonial narrative and an interactive technical disclosure toggle.

## Design Highlights
- **Asymmetric Composition**: 40/60 split with author metadata, location, verification badge, and scale metrics in a distinct left rail.
- **Narrative Storytelling**: Structured with kicker, pull-quote headline, and multi-paragraph engineering narrative.
- **Interactive Disclosure**: "Read Architecture Details" button toggles a technical migration summary without leaving the page.
- **Clear Demonstration Scope**: Explicit disclaimer noting fictional scenario for prototype verification.

## Class Prefix
All styles are strictly scoped under `.ts-story-*`.
