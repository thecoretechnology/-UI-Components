# 06 Video Testimonial Preview

A video thumbnail interview preview pairing a play button overlay, duration badge, and discussion topic tags with an accessible modal dialog simulating video player playback and a full text transcript.

## Design Highlights
- **Realistic Video Thumbnail**: Includes play button hover animation, timestamp overlay (`2:45 MIN`), and discussion topic badges.
- **Accessible Modal Dialog**: Full `role="dialog"`, `aria-modal="true"`, focus management, backdrop dismissal, and `Escape` key trapping.
- **Honest Simulation Disclosure**: Clearly states that media playback is a client-side prototype demonstration without pretending a real media file exists.
- **Included Transcript**: Provides text alternative for interview content.

## Class Prefix
All styles are strictly scoped under `.ts-video-*`.
