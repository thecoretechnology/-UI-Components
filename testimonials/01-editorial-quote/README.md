# 01 Editorial Quote Testimonial

A print-inspired broadsheet quote composition featuring generous whitespace, serif pull-quote typography, publication folios, and an intentional editorial layout that rejects standard cards.

## Design Highlights
- **Print Editorial Layout**: Warm parchment background (`#fcfbf9`) paired with serif italic typography (`Playfair Display`), hairline rules, and running issue folios.
- **Cardless Composition**: Replaces generic elevated rounded cards with a clean, broadsheet typographic statement.
- **Clear Attribution**: Includes author role, publication date, and an explicit non-sponsored demo disclaimer.

## Class Prefix
All styles are strictly scoped under `.ts-edit-*`.
