# 10 — Minimal Utility Navbar (Northstar)

A clean, minimalist navigation bar featuring subtle line divisions, circular utility icon buttons (search and bell notification with unread pip), and an emerald teal CTA.

## Files
- `navbar.html`: Minimal markup with star mark, circular action buttons, and demo pill.
- `navbar.css`: Scoped stylesheet using `--nb-minimal-*` CSS variables.
- `navbar.js`: Mobile menu controller script.

## Usage

```html
<link rel="stylesheet" href="navbars/10-minimal-utility/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/10-minimal-utility/navbar.js"></script>
```
