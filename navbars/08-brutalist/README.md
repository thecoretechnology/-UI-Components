# 08 — Brutalist / Experimental Navbar (NO/FORM®)

A bold neo-brutalist navigation header featuring heavy 2px outlines, 5px hard offset box-shadows, an assertive monospace vibe, and interactive offset-shift click states.

## Files
- `navbar.html`: Neo-brutalist markup with registered trademark badge and tactile CTA button.
- `navbar.css`: Scoped stylesheet using `--nb-brutal-*` CSS variables and hard shadows.
- `navbar.js`: Responsive menu toggle script.

## Usage

```html
<link rel="stylesheet" href="navbars/08-brutalist/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/08-brutalist/navbar.js"></script>
```
