# 04 — Centered Brand Navbar (MAISON°)

A symmetrical 3-column luxury fashion/lifestyle navbar with collections links on the left, high-fashion centered typography, and utility actions (search, account, bag counter) on the right.

## Files
- `navbar.html`: Three-column grid markup with luxury SVG icons and bag counter.
- `navbar.css`: Scoped styling with `--nb-centered-*` variables.
- `navbar.js`: Responsive mobile controller with integrated search input.

## Usage

```html
<link rel="stylesheet" href="navbars/04-centered-brand/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/04-centered-brand/navbar.js"></script>
```
