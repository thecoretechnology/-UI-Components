# 07 — Sidebar Dashboard Navigation (Grove.)

A persistent vertical sidebar layout built for SaaS administration portals, control centers, and workspace dashboards. Features section titles, notification badge counters, user profile card, and transforms into a slide-out drawer with backdrop on mobile.

## Files
- `navbar.html`: Full sidebar layout markup with SVG icons, Pro badge, and user footer.
- `navbar.css`: Scoped stylesheet using `--nb-sidebar-*` CSS variables.
- `navbar.js`: Responsive off-canvas mobile drawer controller with backdrop blur.

## Usage

```html
<link rel="stylesheet" href="navbars/07-sidebar-dashboard/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/07-sidebar-dashboard/navbar.js"></script>
```
