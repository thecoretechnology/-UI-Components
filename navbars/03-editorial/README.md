# 03 — Editorial / Magazine Navbar (The Form.)

An editorial, publication-style navigation bar driven by refined serif typography, crisp line rules, and understated interactive elements. Ideal for journals, architecture firms, publishing houses, and design portfolios.

## Files
- `navbar.html`: Editorial markup with custom two-bar hamburger button and subscription CTA.
- `navbar.css`: Scoped typography and rule styling using `--nb-editorial-*` variables.
- `navbar.js`: Responsive menu toggle script.

## Usage

```html
<!-- Optional: Import Playfair Display font -->
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,500;0,600;1,500&display=swap" rel="stylesheet">
<link rel="stylesheet" href="navbars/03-editorial/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/03-editorial/navbar.js"></script>
```
