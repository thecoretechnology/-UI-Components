# 05 — Floating Pill Navbar (Bloom)

A floating island navigation bar featuring frosted glassmorphism (`backdrop-filter: blur`), soft rounded geometry, and a violet/purple accent.

## Files
- `navbar.html`: Island pill markup with brand icon and action pill.
- `navbar.css`: Glassmorphic styling using `--nb-floating-*` CSS variables.
- `navbar.js`: Responsive floating dropdown controller.

## Usage

```html
<link rel="stylesheet" href="navbars/05-floating-pill/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/05-floating-pill/navbar.js"></script>
```
