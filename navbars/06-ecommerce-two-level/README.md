# 06 — E-commerce Two-Level Navbar (Goodgoods)

A two-level storefront navigation system that clearly separates primary utility functions (search, customer account, saved items, shopping bag) from catalog browsing categories (new arrivals, categories, sale tag).

## Files
- `navbar.html`: Two-tier markup with SVG search input, cart pill, and category links.
- `navbar.css`: Scoped stylesheet using `--nb-shop-*` CSS variables.
- `navbar.js`: Mobile menu controller consolidating search and categories.

## Usage

```html
<link rel="stylesheet" href="navbars/06-ecommerce-two-level/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/06-ecommerce-two-level/navbar.js"></script>
```
