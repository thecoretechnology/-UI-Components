# 09 — Gradient Startup Navbar (Sparkly)

A startup header with a violet-to-purple gradient background (`#4026a8` to `#b45ce0`), sparkle logo mark, and CTA button.

## Files
- `navbar.html`: Gradient header markup with sparkle SVG logo and trial CTA.
- `navbar.css`: Scoped stylesheet using `--nb-gradient-*` CSS variables.
- `navbar.js`: Responsive gradient mobile drawer controller.

## Usage

```html
<link rel="stylesheet" href="navbars/09-gradient-startup/navbar.css">

<!-- Paste navbar.html snippet here -->

<script type="module" src="navbars/09-gradient-startup/navbar.js"></script>
```
